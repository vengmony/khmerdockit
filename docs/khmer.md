## គោលបំណងរបស់គម្រោង

**KhmerDocKit** ជាឧបករណ៍ AI ប្រភពបើកចំហ (open-source) សម្រាប់ស្រុកកម្ពុជា។ វាជួយអ្នកអភិវឌ្ឍន៍កម្ពុជា និងអ្នកជំនួញតូចៗ ដើម្បីទាញយកទិន្នន័យពីឯកសារអាជីវកម្មដូចជា វិក័យប័ត្រ បង្កាន់ដៃ សម្រង់តម្លៃ និងបង្កាន់ផ្ទេរប្រាក់។

## អ្វីដែលយើងផ្តល់ជូន

* **Python library** — `pip install khmerdoc-core`
* **REST API** — FastAPI server (`POST /v1/parse`)
* **Web demo** — Next.js UI
* **CLI** — `khmerdoc parse file.jpg`
* **JSON schemas** — typed documents (`Receipt`, `Invoice`, `Quotation`, `BankSlip`)

## របៀបចូលរួម

* សាកល្បង demo និងផ្តល់មតិរិះគន់ (feedback)។
* បន្ថែម synthetic document template ថ្មី (ឧទាហរណ៍៖ បង្កាន់ដៃផ្សារទំនើប)។
* បកប្រែឯកសារទៅជាភាសាខ្មែរ។
* ជួយសរសេរ validation rule ថ្មី (លេខទូរសព្ទកម្ពុជា កាលបរិច្ឆេទខ្មែរ ។ល។)។

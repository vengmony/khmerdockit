## How to add yourself

1. Fork the repo, add a row to the table above, and open a PR.
2. We'll review the description (no marketing-speak, please — one
   sentence on what you use it for).
3. Once merged, we'll mention you in the next release's CHANGELOG.

## What we ask in return

Nothing, formally. Practically: please

* File bugs you hit, even if you patch around them locally.
* Send a one-line "works for us" note when you upgrade.
* Star the repo if it's not too much trouble — helps the project
  surface for the next person who needs it.

## Privacy

We do not require a customer logo or revenue numbers. A one-line
description ("a POS reconciliation pipeline") is enough.
